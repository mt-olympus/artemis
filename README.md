# Artemis

> [!WARNING]
> ## Archived
> Artemis is no longer maintained and will receive no further releases. It is
> an older Zend Stratigility error middleware and remains available only for
> existing installations. Use the error-handling facilities supplied by your
> current framework, such as Mezzio's error handler for Mezzio applications.

## Historical package

This repository is retained to preserve the source and Composer package for
existing users. It is not compatible with current PHP or framework releases.
